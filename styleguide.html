Utility Classes

  • h1, h2, h3, h4, h5, h6: heading font sizes
  • fs-sz: text font sizes (sz = size value)
  • fw-w: text font weight (w = weight name)
  • ff-primary: primary font family (Poppins)
  • text-color: for text with color #000000
  • radius-sm: border radius of 5px
  • default: for ul and button tags : to reset default behaviour
  • no-decoration: for a tags : to reset default behaviour
  • elem-center: for centering an element
  • elem-hcenter: for horizontal centering an element
  • elem-vcenter: for vertical centering an element
